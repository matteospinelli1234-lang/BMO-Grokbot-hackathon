================================================================================
BMO Grokbot / Tello Talent — Program Overview
================================================================================

This project lets you (1) view a real Tello Talent camera feed and (2) practice
flying in a 3D indoor simulator with furniture obstacles and a Tello-like API.


--------------------------------------------------------------------------------
1. WHAT YOU GET
--------------------------------------------------------------------------------

  tello_video.py       Live camera from a real Tello (or --simulate fake feed)
  tello_simulator.py   3D flight simulator (keyboard + Python API)
  tello_sim/           Simulator package (physics, world, render, API)
  examples/            Demo and smoke-test scripts
  requirements.txt     Python dependencies
  .venv/               Recommended virtual environment


--------------------------------------------------------------------------------
2. SETUP
--------------------------------------------------------------------------------

  cd /path/to/bmo-grokbot-hackathon
  source .venv/bin/activate
  pip install -r requirements.txt

  Uses pygame-ce (not classic pygame) for Python 3.14 compatibility.


--------------------------------------------------------------------------------
3. REAL TELLO VIDEO  (tello_video.py)
--------------------------------------------------------------------------------

  How it works:
    - Connects to the drone over Wi-Fi (default IP 192.168.10.1) via djitellopy
    - Starts the H.264 stream and shows frames in an OpenCV window
    - Does NOT fly the drone; video only

  Run:
    1. Power on the Tello Talent
    2. Connect your PC to the drone Wi-Fi (TELLO-XXXXXX)
    3. python tello_video.py
       python tello_video.py --fps-overlay --scale 1.5
       python tello_video.py --simulate          # no drone; synthetic feed
       python tello_video.py --simulate --headless --duration 2

  Keys:  q / Esc = quit,  s = save snapshot to ./snapshots/


--------------------------------------------------------------------------------
4. 3D FLIGHT SIMULATOR  (tello_simulator.py + tello_sim/)
--------------------------------------------------------------------------------

  How it works (data flow):

    Keyboard ──┐
               ├──> Drone physics (position, yaw, RC, scripted moves)
    Python API ┘              │
                              ▼
                         Collision vs furniture
                              │
                              ▼
                    Renderer (chase cam + FPV + HUD)
                              │
                              ▼
                         pygame window

  World (from PAD2.step CAD map):
    - Real hall footprint ~24 x 12 m, flyable height ~4.35 m (primary ceiling)
    - Spawn = HUB.origin (editable in zone editor; default 0,0,0)
    - Coordinates: x = right, y = forward, z = up
    - Yaw 0 looks along +y; positive yaw is clockwise from above
    - Solids from the STEP file become AABB obstacles (columns, platforms,
      blocks, ceiling). The outer shell becomes walls + floor bounds.
    - Extra scenario props (tello_sim/world.py): thin wall on the PAD ↔
      UNDER_MEZZ border, plus a 1×1 m column from floor to ceiling at the
      ZONE_7 ↔ HUB ↔ UNDER_MEZZ corner (footprint inside ZONE_7).
    - Keep-out bubble SAFE_RADIUS = 0.40 m (40 cm) around the drone centre —
      physics + path planning refuse to enter this "death zone" (models real
      flight position imprecision). Chase cam draws the bubble while flying.
    - Hitting the bubble against a side stops the drone (HUD shows CONTACT)
    - Landing on a top (Space / land()) perches there (HUD shows PERCHED)
    - Takeoff from a perch rises relative to that surface
    - Loader: tello_sim/step_map.py  |  map file: PAD2.step
    - Navigation zones (visible overlays, toggle with Z):
        HUB, PAD, COLUMN_ROW, AISLE_EAST, AISLE_WEST, UNDER_MEZZ, MEZZ_TOP,
        UNDER_NW_DECK, NW_DECK, SOUTH_BLOCK, NORTH_OPEN
      Defined in tello_sim/zones.py — HUD shows the active zone id.
      HUB has an extra orange "origin" point = sim takeoff / connect spawn.
      Collision-aware tour of every zone:
        python examples/tour_zones.py
        python examples/tour_zones.py --headless
        python examples/tour_zones.py --no-visual
      Scripted go_to_xyz() turns to face the travel direction (FPV forward).
      Edit zones visually (rectangles on the PAD2 map):
        python zone_editor.py
        — drag corners / hover / origin (orange diamond on HUB)
        — [ ] zmin, - = zmax, H ensure HUB, S save → zones.json
        Sim + tour auto-load zones.json when present.
      Text control of the sim (zone-to-zone):
        python tello_commander.py
        tello> go from PAD to NORTH
        tello> go to MEZZ TOP
        tello> status
        tello> land
        tello> quit
      Real Tello Talent commander (WASD pilot + text; agent-ready):
        python tello_irl_commander.py              # real AP Wi-Fi
        python tello_irl_commander.py --sim        # same UI on the sim
        python tello_irl_commander.py -c takeoff -c "go to NORTH" -c land
        API: from tello_irl import DroneSession
             session.execute("go to NORTH") / session.set_rc(...)
      Cursor-as-pilot (NL in chat → drone), kill switch on the bridge:
        python tello_agent_bridge.py --auto        # terminal 1 (keep open)
        # In Cursor chat: "move from the beginning to area 7"
        # Optional local NL console: python tello_nl_console.py
        Bridge: http://127.0.0.1:8765  (/nl /exec /status /abort)

  Visuals:
    - Main view: chase camera (press C for orbit)
    - Top-right: onboard FPV of the same room
    - HUD: status, battery, xyz, yaw, height, FPS

  Run interactive:
    python tello_simulator.py
    python tello_simulator.py --duration 60
    python tello_simulator.py --width 1600 --height 900

  Keyboard:
    Space     takeoff / land
    W / S     forward / back
    A / D     left / right
    R / F     up / down
    Q / E     yaw
    C         chase <-> orbit camera
    Esc       quit


--------------------------------------------------------------------------------
5. PYTHON API  (tello_sim.SimulatedTello)
--------------------------------------------------------------------------------

  Same style as djitellopy, but drives the virtual drone in-process.
  By default it opens the 3D window in a background thread so you can watch.

  Example:
    from tello_sim import SimulatedTello

    tello = SimulatedTello()       # visual=True by default
    tello.connect()
    tello.takeoff()
    tello.move_forward(50)         # centimetres
    tello.rotate_clockwise(90)
    tello.land()
    tello.end()

  Demo script:
    python examples/fly_square.py

  Headless (physics only, no window):
    tello = SimulatedTello(visual=False)

  Main methods:
    connect / end
    takeoff / land
    move_forward / back / left / right / up / down (cm)
    rotate_clockwise / rotate_counter_clockwise (degrees)
    send_rc_control(lr, fb, ud, yaw)   # sticks -100..100
    get_battery() / get_height()
    get_frame_read().frame             # FPV as BGR numpy array

  Scripted moves are blocking until the target is reached (or collision aborts).


--------------------------------------------------------------------------------
6. FILE MAP (tello_sim package)
--------------------------------------------------------------------------------

  tello_sim/__init__.py   Exports SimulatedTello
  tello_sim/drone.py      State, RC, takeoff/land, move targets, collision
  tello_sim/world.py      Room mesh + tables/boxes/shelves + AABB collision
  tello_sim/render.py     Perspective projection, chase/FPV, HUD
  tello_sim/api.py        SimulatedTello wrapper
  tello_sim/app.py        pygame loop, keyboard, shared drone instance

  examples/fly_square.py  Scripted square path
  examples/smoke_sim.py   Automated takeoff/move/land check
  snapshots/              Saved images from video / headless runs


--------------------------------------------------------------------------------
7. REAL DRONE vs SIMULATOR
--------------------------------------------------------------------------------

  Real hardware video:     python tello_video.py
  Fake video only:         python tello_video.py --simulate
  Practice flying (3D):    python tello_simulator.py
  Practice with scripts:   from tello_sim import SimulatedTello

  SimulatedTello is NOT a network stand-in for a Wi-Fi Tello. When you are ready
  for the real craft, use djitellopy.Tello on the drone's Wi-Fi with the same
  style of commands (takeoff, move_*, etc.).


--------------------------------------------------------------------------------
8. QUICK TROUBLESHOOTING
--------------------------------------------------------------------------------

  - Activate .venv before running (system Python may have headless OpenCV).
  - Import error for pygame:  pip install pygame-ce
  - Real Tello won't connect: PC must be on TELLO Wi-Fi; drone powered on.
  - Keyboard does nothing: click the simulator window to focus it.
  - Stuck against furniture: climb (R) or yaw around; CONTACT = collision.

  Verify physics without a GUI:
    python examples/smoke_sim.py
